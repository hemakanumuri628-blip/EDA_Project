# Exploratory Data Analysis (EDA) Project

## Project Title
Employee Data Analysis using Python

## Objective
To analyze employee dataset and find patterns, trends, and relationships using data visualization.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
Employee dataset contains:
- Name
- Age
- Salary
- Department
- Experience

## Steps Performed
1. Loaded dataset using pandas
2. Handled missing values
3. Removed duplicate records
4. Performed statistical analysis
5. Created visualizations (graphs)

## Visualizations
- Age Distribution
- Salary Distribution
- Department Count
- Experience vs Salary
- Correlation Heatmap

## Insights
- IT department has more employees
- Salary increases with experience
- Positive relationship between experience and salary

## Conclusion
This project helps to understand data patterns and improve analytical skills using Python.
